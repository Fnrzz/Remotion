# Sumber untuk keterangan unggahan

Kronos adalah model fondasi untuk rangkaian data pasar finansial. Alur yang didokumentasikan memproses angka, bukan screenshot grafik. Paper awal diajukan pada 2 Agustus 2025. Diagram dan data dalam video ini dibuat untuk penjelasan, bukan hasil eksekusi model atau harga pasar terkini.

Sumber asli:

- Repositori dan dokumentasi: https://github.com/shiyu-coder/Kronos
- Kartu model resmi: https://huggingface.co/NeoQuasar/Kronos-base
- Paper asli: Yu Shi dkk., _Kronos: A Foundation Model for the Language of Financial Markets_, arXiv:2508.02739v1. https://arxiv.org/html/2508.02739v1
- Tanggal pengajuan paper: https://arxiv.org/abs/2508.02739v1
- Demo resmi, dibaca sebagai contoh historis, bukan ramalan terkini: https://shiyu-coder.github.io/Kronos-demo/
